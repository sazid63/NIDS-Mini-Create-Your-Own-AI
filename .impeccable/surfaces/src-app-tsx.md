# Surface brief: NIDS Mini guide (src/App.tsx and its pages)

Mode: Read (a step-by-step guide). Build path: code-led.
Audience: beginners from age 12. Job: follow five phases, run the commands, understand every part of the code, end with a deployed AI.
Proof: every number comes from the real run of ai-project/ (99.66% accuracy, 80.7% Macro F1, 3,518,319 parameters).
Unresolved: none.

## Direction contract

THESIS: The guide is a small exhibition you walk through, five rooms, one per phase. It refuses the dark "hacker terminal" dashboard that every security tutorial ships and the cream-paper kids-book rendition.
OWN-WORLD: Gallery-white ground (cool, #F3F4F8) and deep ink-navy text. Each room owns one saturated wall colour (data amber, brain violet, training coral, testing teal, deploy blue) that fills the room's opener band, step numerals and code-part markers. Type: Bricolage Grotesque for room titles and big numerals, Atkinson Hyperlegible for reading text, JetBrains Mono for code. Wall-label cards (white, hairline, 4px corner) for glossary words and "what this does" notes. Hand-made inline SVG plates, flat colour, one per room.
STORY: The learner sees where they are in the five-room map, reads a one-sentence promise, studies the room's plate, then follows numbered steps; each command and each coloured code part is explained right beside it. They believe "I can build this" and finish by deploying.
FIRST VIEWPORT: Left: a visitor-map rail listing Welcome and Rooms 1-5 with the current room's wall colour as a block. Right: the room opener band in the wall colour with a huge room numeral, title, and one plain sentence; directly under it the illustration plate, full column width. Reading column about 68 characters, 17-18px body. First action: "Start step 1" anchored below the plate.
FORM: Exhibition wall-label system, own grounded list position 7, seed:1c3b30dcf4777501.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
