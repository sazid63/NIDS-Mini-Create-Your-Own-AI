# 🛡️ NIDS Mini: Learn to build an AI

> **A beginner-friendly, zero-jargon interactive masterclass for building an AI Network Intrusion Detector from scratch in PyTorch.**

---

## 🌟 Visual Theme & Overview

**NIDS Mini** is designed as a personal AI mentor and visual masterclass for learners of all backgrounds. It demystifies artificial intelligence and cybersecurity by breaking down complex neural networks, data pipelines, and security metrics into intuitive visual cards, math diagrams, beginner-friendly glossaries, and chunk-by-chunk Python code.

---

## 📚 Masterclass Modules (Left Sidebar Navigation)

1. **Introduction & Overview**: What you are building, learning objectives, and system architecture.
2. **Phase 1: Data Explorer (Good vs Bad Data)**: Exploring real-life messy network traffic vs. clean project data, CIC-IDS2017 origins, and manual data cleaning.
3. **Phase 2: Building the AI Brain (ResFlowNet)**: Coding a 3.18M parameter neural network with skip connections in PyTorch.
4. **Phase 3: Teaching & Training the AI**: Running custom training loops with AdamW and Focal Loss.
5. **Phase 4: Testing & SOC Evaluation**: Measuring precision, recall, and Macro F1-score like a Security Operations Center analyst.
6. **Phase 5: Deploying for Real-Time Defense**: Exporting to ONNX for sub-millisecond (0.06ms) edge inference.
7. **Phase 6: Final Execution & Live Demo**: Step-by-step terminal guides and live threat detection preview.

## 🚀 Quick Start & Installation

Clone this repository and run the application locally:

```bash
# 1. Clone the repository
git clone https://github.com/your-username/nids-mini.git
cd nids-mini

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons.
- **AI Engine**: PyTorch, Scikit-Learn, ONNX Runtime.
- **Build Tool**: Vite.
